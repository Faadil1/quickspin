The remaining decorative coral glow in the hero instrument was replaced with violet. Coral remains reserved for refusal, failure, and warning semantics.

## Runtime proof

Vite now emits /build.json with source SHA, deployment identifier when available, deployment URL, environment, and build timestamp. Git deployments use VERCEL_GIT_COMMIT_SHA; manual builds can inject GIT_COMMIT.

## Verification gate

Promotion requires release verification plus public-runtime verification of the emitted build.json and the five product routes.
